StaffApp КПП 5.0

Тестові паролі після активації:
- Керівник: 1111
- Охоронець: 111

Важливо:
- У цій збірці увімкнений тестовий режим, щоб можна було перевіряти плагін без Payhip ліцензії.
- Перед продажем вимкни тестовий режим у WordPress → StaffApp → Основні налаштування.
- Після вимкнення тестового режиму StaffApp відкриється тільки після активації License Key Payhip і прив'язки до поточного домену.

Модулі:
- Працівники: фото до 5, розпізнавання одного/кількох облич, прихід/вихід, звільнення/відновлення, журнал.
- Охоронці: додавання, зміна пароля, видалення.
- Транспорт: номер авто, номер причепа, марка, фірма, водій, телефон, вантаж, брутто, тара, нетто, заїзд/виїзд.
- Розпізнавання облич: до 5 фото на працівника; сумнівні й неоднозначні збіги не підтверджуються автоматично.
- OCR номерів: повторне читання оригінального та покращеного кадру; номер підставляється лише за достатньої впевненості.
- PWA: кнопка встановлення ярлика/додатку.

Якість розпізнавання:
- Для фото працівника використовуйте чітке зображення рівно одного обличчя, прямо перед камерою, без тіней і сильного контрового світла.
- Для сканування номера зупиніть авто, наведіть камеру прямо на номер і забезпечте рівномірне освітлення. Якщо два проходи OCR не погоджуються, введіть номер вручну.
- Розпізнавання залежить від камери, освітлення та якості зображення й не може гарантувати відсутність помилок. Перед фіксацією звіряйте результат із людиною; сумнівний результат не слід використовувати для автоматичного рішення.
